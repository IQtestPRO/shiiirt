# Busca e organização automática de imagens

## Objetivo
Executar busca e organização automática de imagens de forma repetível, rastreável e acionável.

## Pré-requisitos
- URL ou projeto local.
- Objetivo de conversão.
- Acesso a código, analytics ou export de dados quando necessário.
- Ambiente para salvar relatórios.

## Passos
1. Definir função da imagem.
2. Buscar Unsplash/Pexels/Pixabay/Openverse.
3. Verificar licença.
4. Salvar metadados.
5. Baixar apenas candidatos seguros.
6. Gerar prompts alternativos.

## Saídas
- Relatório Markdown.
- Lista de tarefas priorizadas.
- Evidências com links, screenshots ou métricas.
- Critério de pronto por tarefa.

## Automação com Codex
Peça ao agente: "Execute busca e organização automática de imagens neste projeto, salve relatório em /reports e aplique correções de baixo risco automaticamente".
