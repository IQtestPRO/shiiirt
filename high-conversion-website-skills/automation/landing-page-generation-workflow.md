# Geração automática de landing page

## Objetivo
Executar geração automática de landing page de forma repetível, rastreável e acionável.

## Pré-requisitos
- URL ou projeto local.
- Objetivo de conversão.
- Acesso a código, analytics ou export de dados quando necessário.
- Ambiente para salvar relatórios.

## Passos
1. Selecionar template.
2. Coletar oferta/persona/prova.
3. Gerar wireframe.
4. Criar copy.
5. Gerar componentes.
6. Instrumentar analytics.
7. Validar mobile.

## Saídas
- Relatório Markdown.
- Lista de tarefas priorizadas.
- Evidências com links, screenshots ou métricas.
- Critério de pronto por tarefa.

## Automação com Codex
Peça ao agente: "Execute geração automática de landing page neste projeto, salve relatório em /reports e aplique correções de baixo risco automaticamente".
