# Setup automático de eventos de analytics

## Objetivo
Executar setup automático de eventos de analytics de forma repetível, rastreável e acionável.

## Pré-requisitos
- URL ou projeto local.
- Objetivo de conversão.
- Acesso a código, analytics ou export de dados quando necessário.
- Ambiente para salvar relatórios.

## Passos
1. Mapear funil.
2. Escolher eventos GA4 recomendados.
3. Criar dataLayer contract.
4. Implementar helpers TypeScript.
5. Validar debug.
6. Documentar dicionário.

## Saídas
- Relatório Markdown.
- Lista de tarefas priorizadas.
- Evidências com links, screenshots ou métricas.
- Critério de pronto por tarefa.

## Automação com Codex
Peça ao agente: "Execute setup automático de eventos de analytics neste projeto, salve relatório em /reports e aplique correções de baixo risco automaticamente".
