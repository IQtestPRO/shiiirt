# Geração automática de copy

## Objetivo
Executar geração automática de copy de forma repetível, rastreável e acionável.

## Pré-requisitos
- URL ou projeto local.
- Objetivo de conversão.
- Acesso a código, analytics ou export de dados quando necessário.
- Ambiente para salvar relatórios.

## Passos
1. Coletar voz do cliente.
2. Mapear objeções.
3. Criar promessa.
4. Gerar headlines e CTAs.
5. Criar FAQ.
6. Preparar variações para teste.

## Saídas
- Relatório Markdown.
- Lista de tarefas priorizadas.
- Evidências com links, screenshots ou métricas.
- Critério de pronto por tarefa.

## Automação com Codex
Peça ao agente: "Execute geração automática de copy neste projeto, salve relatório em /reports e aplique correções de baixo risco automaticamente".
