# Checklist operacional - Web Performance and Core Web Vitals

## Preparação
- [ ] Confirmar url
- [ ] Confirmar build
- [ ] Confirmar lista de assets
- [ ] Confirmar scripts terceiros
- [ ] Confirmar dados rum

## Execução
- [ ] Medir lab e campo
- [ ] Identificar LCP element
- [ ] Otimizar imagem e fonte crítica
- [ ] Reduzir JS e terceiros
- [ ] Reservar espaço de layout
- [ ] Monitorar regressões

## QA
- [ ] LCP <= 2.5s p75
- [ ] INP <= 200ms p75
- [ ] CLS <= 0.1 p75
- [ ] Hero otimizado
- [ ] Imagens WebP/AVIF
- [ ] Scripts deferidos
- [ ] RUM ativo

## Métricas para conferir
- [ ] LCP
- [ ] INP
- [ ] CLS
- [ ] TTFB
- [ ] conversion_rate
- [ ] bounce_rate

## Critério de pronto
- A recomendação está ligada a uma métrica.
- A mudança tem dono, prazo e forma de validação.
- O impacto esperado está documentado antes da publicação.
