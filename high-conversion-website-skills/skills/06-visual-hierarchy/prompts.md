# Prompts - Visual Hierarchy

## Prompt de auditoria
Você é especialista em Visual Hierarchy. Audite a página abaixo com foco em CTA_click_rate, scroll_depth, time_on_page, task_success_rate. Gere achados priorizados, impacto esperado, esforço, evidência necessária e próximos passos.

## Prompt de implementação
Use a skill Visual Hierarchy para implementar melhorias em um projeto Next.js/React/Tailwind. Preserve padrões existentes, gere componentes acessíveis e adicione eventos de analytics quando aplicável.

## Prompt de nicho SaaS B2B
Adapte Visual Hierarchy para SaaS B2B com foco em demo/trial. Use prova social B2B, objeções de risco, segurança, integração e ROI.

## Prompt de nicho E-commerce
Adapte Visual Hierarchy para e-commerce com foco em add-to-cart, checkout e compra. Priorize imagens, frete, troca, reviews, preço e confiança.

## Prompt de nicho Infoproduto
Adapte Visual Hierarchy para curso online com foco em lead e venda. Priorize transformação, autoridade, módulos, garantia, bônus e urgência ética.
