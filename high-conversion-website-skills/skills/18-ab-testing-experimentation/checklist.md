# Checklist operacional - A/B Testing and Experimentation

## Preparação
- [ ] Confirmar hipótese
- [ ] Confirmar baseline
- [ ] Confirmar mde
- [ ] Confirmar tráfego
- [ ] Confirmar métrica
- [ ] Confirmar ferramenta

## Execução
- [ ] Definir hipótese
- [ ] Escolher métrica primária
- [ ] Calcular amostra/MDE
- [ ] Criar variações
- [ ] QA técnico
- [ ] Rodar até critério definido
- [ ] Documentar decisão

## QA
- [ ] Hipótese falsificável
- [ ] Métrica primária
- [ ] Guardrails
- [ ] Amostra estimada
- [ ] Segmentação correta
- [ ] Sem mudanças simultâneas
- [ ] Resultado documentado

## Métricas para conferir
- [ ] conversion_rate
- [ ] uplift
- [ ] statistical_power
- [ ] revenue_per_visitor
- [ ] guardrail_metrics

## Critério de pronto
- A recomendação está ligada a uma métrica.
- A mudança tem dono, prazo e forma de validação.
- O impacto esperado está documentado antes da publicação.
