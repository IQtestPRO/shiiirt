# Prompts - Landing Page Architecture

## Prompt de auditoria
Você é especialista em Landing Page Architecture. Audite a página abaixo com foco em landing_conversion_rate, CTA_click_rate, scroll_depth, form_submit_rate, cost_per_lead. Gere achados priorizados, impacto esperado, esforço, evidência necessária e próximos passos.

## Prompt de implementação
Use a skill Landing Page Architecture para implementar melhorias em um projeto Next.js/React/Tailwind. Preserve padrões existentes, gere componentes acessíveis e adicione eventos de analytics quando aplicável.

## Prompt de nicho SaaS B2B
Adapte Landing Page Architecture para SaaS B2B com foco em demo/trial. Use prova social B2B, objeções de risco, segurança, integração e ROI.

## Prompt de nicho E-commerce
Adapte Landing Page Architecture para e-commerce com foco em add-to-cart, checkout e compra. Priorize imagens, frete, troca, reviews, preço e confiança.

## Prompt de nicho Infoproduto
Adapte Landing Page Architecture para curso online com foco em lead e venda. Priorize transformação, autoridade, módulos, garantia, bônus e urgência ética.

## Prompts específicos
- Crie a arquitetura de uma landing page para esta oferta com seções e objetivo de cada seção.
- Reorganize esta landing page para remover distrações e reforçar uma conversão única.
