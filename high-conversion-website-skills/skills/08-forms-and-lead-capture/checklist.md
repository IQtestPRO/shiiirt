# Checklist operacional - Forms and Lead Capture

## Preparação
- [ ] Confirmar campos necessários
- [ ] Confirmar destino do lead
- [ ] Confirmar crm
- [ ] Confirmar política de privacidade
- [ ] Confirmar critérios de qualificação

## Execução
- [ ] Definir qualificação mínima
- [ ] Remover campos não essenciais
- [ ] Usar labels persistentes
- [ ] Adicionar validação útil
- [ ] Testar uma ou duas etapas
- [ ] Medir start, error e submit

## QA
- [ ] Campos mínimos
- [ ] Labels visíveis
- [ ] Autocomplete correto
- [ ] Input types mobile
- [ ] Erros próximos ao campo
- [ ] Privacidade clara
- [ ] Evento generate_lead

## Métricas para conferir
- [ ] form_start_rate
- [ ] form_submit_rate
- [ ] field_error_rate
- [ ] lead_quality
- [ ] cost_per_lead

## Critério de pronto
- A recomendação está ligada a uma métrica.
- A mudança tem dono, prazo e forma de validação.
- O impacto esperado está documentado antes da publicação.
