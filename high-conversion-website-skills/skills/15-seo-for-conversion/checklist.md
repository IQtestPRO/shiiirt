# Checklist operacional - SEO for Conversion

## Preparação
- [ ] Confirmar keywords
- [ ] Confirmar páginas
- [ ] Confirmar oferta
- [ ] Confirmar catálogo
- [ ] Confirmar dados search console
- [ ] Confirmar conversões

## Execução
- [ ] Mapear intenção por página
- [ ] Criar title/meta orientados a clique qualificado
- [ ] Adicionar estrutura H1-H3
- [ ] Criar links internos para conversão
- [ ] Implementar JSON-LD
- [ ] Medir conversões por landing orgânica

## QA
- [ ] Intenção clara
- [ ] Title único
- [ ] Meta com valor
- [ ] H1 alinhado
- [ ] CTA contextual
- [ ] Schema correto
- [ ] Links internos
- [ ] Search Console monitorado

## Métricas para conferir
- [ ] organic_clicks
- [ ] CTR_serp
- [ ] organic_conversion_rate
- [ ] qualified_leads
- [ ] revenue_from_organic

## Critério de pronto
- A recomendação está ligada a uma métrica.
- A mudança tem dono, prazo e forma de validação.
- O impacto esperado está documentado antes da publicação.
