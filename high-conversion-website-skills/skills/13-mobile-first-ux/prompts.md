# Prompts - Mobile-First UX

## Prompt de auditoria
Você é especialista em Mobile-First UX. Audite a página abaixo com foco em mobile_conversion_rate, mobile_CTA_click_rate, LCP_mobile, form_submit_rate, checkout_completion_rate. Gere achados priorizados, impacto esperado, esforço, evidência necessária e próximos passos.

## Prompt de implementação
Use a skill Mobile-First UX para implementar melhorias em um projeto Next.js/React/Tailwind. Preserve padrões existentes, gere componentes acessíveis e adicione eventos de analytics quando aplicável.

## Prompt de nicho SaaS B2B
Adapte Mobile-First UX para SaaS B2B com foco em demo/trial. Use prova social B2B, objeções de risco, segurança, integração e ROI.

## Prompt de nicho E-commerce
Adapte Mobile-First UX para e-commerce com foco em add-to-cart, checkout e compra. Priorize imagens, frete, troca, reviews, preço e confiança.

## Prompt de nicho Infoproduto
Adapte Mobile-First UX para curso online com foco em lead e venda. Priorize transformação, autoridade, módulos, garantia, bônus e urgência ética.
