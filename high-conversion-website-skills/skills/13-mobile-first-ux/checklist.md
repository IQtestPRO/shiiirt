# Checklist operacional - Mobile-First UX

## Preparação
- [ ] Confirmar páginas críticas
- [ ] Confirmar breakpoints
- [ ] Confirmar dados mobile
- [ ] Confirmar componentes

## Execução
- [ ] Começar pelo viewport 360-390px
- [ ] Priorizar conteúdo decisivo
- [ ] Usar targets de toque grandes
- [ ] Reduzir imagens decorativas
- [ ] Criar CTA sticky quando útil
- [ ] Testar teclado e formulários

## QA
- [ ] Sem scroll horizontal
- [ ] Alvos 44px+
- [ ] Texto 16px+
- [ ] CTA visível
- [ ] Imagens informativas
- [ ] Inputs corretos
- [ ] Performance em 4G

## Métricas para conferir
- [ ] mobile_conversion_rate
- [ ] mobile_CTA_click_rate
- [ ] LCP_mobile
- [ ] form_submit_rate
- [ ] checkout_completion_rate

## Critério de pronto
- A recomendação está ligada a uma métrica.
- A mudança tem dono, prazo e forma de validação.
- O impacto esperado está documentado antes da publicação.
