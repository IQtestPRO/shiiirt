# Checklist de licença e uso de imagem

Este projeto foi declarado pelo cliente como protótipo sem fins comerciais. Mesmo assim, cada imagem usada deve manter origem e rastreabilidade para troca futura por material licenciado.

## Status

- `approved_noncommercial`: permitido pelo cliente para protótipo sem fins comerciais.
- `reference_only`: usar apenas como referência visual, sem publicar.
- `pending_review`: origem encontrada, mas ainda precisa validação.
- `rejected`: não usar.

## Checklist antes de publicar

- Produto corresponde ao SKU em `data/products.json`.
- Temporada/modelo/versão visual conferidos.
- Origem registrada no manifesto.
- URL fonte salva.
- Imagem sem watermark.
- Resolução suficiente para vitrine.
- Arquivo final otimizado.
- Alt text criado.
- Risco anotado em `rightsNotes`.

## Restrições práticas

- Não burlar login, paywall, CAPTCHA ou bloqueio técnico.
- Não remover watermark.
- Não usar fotos de atletas/modelos quando houver alternativa de produto em fundo limpo.
- Não declarar “oficial” no texto público sem comprovação.
- Para uso comercial futuro, substituir por imagens licenciadas/autorizadas.
